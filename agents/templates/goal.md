# Goal

**Kind:** goal

## Job

When [situation], I want to [progress], so I can [outcome].

## Outcome

What is true when this job is done.

## Release intent

What ships, and what this goal does not fold into.

## Split judgment

Independently testable parts become capabilities. Parts that require each other stay one capability. One implementation unit stays one record. Shipping together sets the order. It does not merge the records.
