# Jobs-to-be-Done (JTBD) Framing

## 1. Job Statement
**When** [situation, context, or triggering event],
**I want to** [core motivation, functional action, or process],
**So I can** [desired outcome, progress, or business value].

## 2. Struggling Moments & Context
- **Trigger Scenario**: [Specific moment the customer experiences friction]
- **Current Alternatives / Workarounds**: [How the user solves this today (spreadsheets, manual steps, competitor)]
- **Failure of Current Alternative**: [Why the current approach breaks down]

## 3. The Four Forces of Progress
| Force | Analysis & Evidence |
| :--- | :--- |
| **Push** (Pain of today) | [Frustrations and costs of the current status quo] |
| **Pull** (Attraction of new) | [Desired capabilities and future state] |
| **Anxiety** (Fear of new) | [Perceived risks, learning curve, migration friction] |
| **Inertia** (Comfort with old) | [Habits, existing tooling lock-in, organizational reluctance] |

## 4. Multi-Dimensional Job Breakdown
- **Functional Job**: [Objective, observable tasks to accomplish]
- **Emotional Job**: [Personal emotional relief or confidence sought]
- **Social Job**: [How the user wishes to be perceived by peers or leadership]

## 5. Hire & Fire Criteria
- **Hire Criteria (Adoption triggers)**: [Must-have capabilities that justify adopting this solution]
- **Fire Criteria (Abandonment triggers)**: [Flaws or regressions that would cause the user to fire this solution]
