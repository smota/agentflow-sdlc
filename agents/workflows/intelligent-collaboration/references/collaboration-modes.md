# Collaboration modes

| Mode                 | Pattern                           | Use                               |
| -------------------- | --------------------------------- | --------------------------------- |
| `single-agent`       | normal orchestration              | clear low-risk work               |
| `advisory`           | scoped scout or critique sandwich | focused second opinion            |
| `council`            | role-local panel                  | high-uncertainty strategy         |
| `parallel-discovery` | bounded read-only fanout          | broad repo discovery              |
| `spike`              | isolated worktree experiment      | uncertain implementation approach |
| `human-gated`        | human authority gate              | high-assurance or sensitive work  |

Use the smallest sufficient collaboration mode. Do not escalate modes for optional polish.
