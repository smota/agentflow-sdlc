# Evidence audit checklist

- [ ] Collaboration mode recorded.
- [ ] Smallest-sufficient reason recorded.
- [ ] Helpers and permissions recorded.
- [ ] Transport/delegation/context boundaries recorded where helpers ran.
- [ ] Parent synthesis recorded.
- [ ] Dissent/critique disposition recorded or `none`.
- [ ] Raw transcript local-only status recorded.
- [ ] Validation result recorded.
- [ ] No false multi-agent/council claim.
