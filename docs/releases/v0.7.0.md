# AgentFlow SDLC v0.7.0 — Multi-agent efficiency and SDLC patterns

This release introduced formal multi-agent workflow patterns while preserving durable evidence and expanded the documentation of AgentFlow's core rules.

## What changed

### Multi-agent efficiency patterns

- **Dual-write handoffs:** the orchestrator can keep detailed local design material under `.agent-runs/scratch/` while posting a durable, high-fidelity summary to the GitHub issue.
- **Architectural sprints:** the architect can evaluate a related issue batch collectively before implementation begins.
- **Opt-in design gates:** an explicit request can pause work after architecture so a human reviews the design before implementation.
- **Bounded role templates:** architect and implementer handoff templates clarify ownership during phase transitions.

### Documentation and core principles

- **Core tenets:** the project maps SDLC problems to AgentFlow controls.
- **Human/agent parity:** humans and agents follow the same public issue and PR contract.
- **Issue standards:** templates separate the problem statement from technical design.
- **Lifecycle visual:** documentation shows the issue-to-PR workflow.

## Upgrade guidance

From a source checkout, sync an adopted project with:

```bash
node bin/cli.mjs sync --target /path/to/project
```

Review the proposed and applied changes according to the target project's update policy.
