# AgentFlow SDLC v1.2.0 — Recoverable delivery and scoped consent

AgentFlow SDLC 1.2.0 adds scoped intent consent, recoverable delivery actions, and asynchronous engineering provider support. Teams can inspect what a run is authorized to do, recover interrupted operations, and keep qualification evidence separate from implementation claims.

## Bind a run to the intent the user accepted

New delivery runs require host-observed consent before phase zero advances. The consent binds the frozen goal, plan, source revision, destination, checks, and business-action ceiling. Changed inputs invalidate the decision.

Intent consent does not authorize PR creation or merge. Those actions require their own bounded grants, and high-assurance human gates remain separate. This cooperative receipt records the host's observation; it does not authenticate human identity.

## Recover delivery actions without repeating their effects

Typed grants constrain delegated actions by destination, expiry, and allowances. Public delivery commands support explicit ready-PR creation and reconciliation of PR and merge outcomes. A write-ahead journal preserves admitted operations so a fresh process can reconcile an interrupted response before attempting another action.

Recovery checks cover revoked or exhausted grants, source unavailability, lost acknowledgements, and filesystem exhaustion. The published qualification exercised PR creation and merge only against a named disposable destination. Standard open-PR policy does not acquire merge authority from that experiment.

## Keep engineering work asynchronous and provider-neutral

The Meshloop adapter supports a detached lifecycle for submission, status, cancellation, timeout, and reconciliation. Neutral engineering contracts check operation and candidate identity, terminal status, and raw artifact bytes. Direct providers remain available when optional Meshloop support is absent.

The installed Meshloop binary used in qualification did not expose the required integrated lifecycle contract. Integrated live Meshloop execution remains unsupported for that binary; adapter tests do not establish live runtime support. The Codex probe verified a structured response, but live editing and cancellation remain unqualified on the tested host.

## Resume from durable evidence and inspect actual costs

Portable handoff and resume now recheck source state, workspace identity, artifact digests, and active grants. Unknown Git locks are preserved. Segmented storage rejects missing tails, inconsistent counts, and corrupt snapshots; migration requires preview and fresh source verification.

Context reuse and telemetry provide clearer accounting of attempts, stages, observed HTTP responses, and missing measurements. Telemetry remains optional. The documented source-request reduction and telemetry-overhead targets have not been met; this release makes no general efficiency guarantee.

## Install and update

Node.js 20 or newer is required. Install this GitHub release explicitly:

```bash
npm install -g github:smota/agentflow-sdlc#v1.2.0
agentflow-sdlc doctor-env --target /path/to/your-project
agentflow-sdlc adopt plan --profile standard --target /path/to/your-project --json
```

Review the adoption plan before applying changes with `adopt apply`. Follow the exact plan and confirmation procedure in [run operations](../run-operations.md) and the [getting started guide](../get-started.md). Existing installation ownership and drift checks still apply. This release does not publish an npm-registry package.

## Compatibility and qualification limits

- This is a minor release in the 1.x line. Existing event chains remain readable; old phase-zero advances are not retroactively represented as consented. New runs must supply the scoped consent described above.
- No automatic state-store migration or installed-runtime replacement is performed by publishing this release.
- Hard provider spending ceilings, authenticated human consent, full live engineering-provider qualification, and the complete adoption matrix remain outside the demonstrated scope.
- Remaining qualification is tracked in [#302](https://github.com/smota/agentflow-sdlc/issues/302), [#303](https://github.com/smota/agentflow-sdlc/issues/303), and [#304](https://github.com/smota/agentflow-sdlc/issues/304).
