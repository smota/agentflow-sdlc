# AgentFlow SDLC v1.9.0 — Recursive self-improvement pipeline and grounded steering triage

AgentFlow SDLC 1.9.0 introduces an autonomous closed-loop Recursive Self-Improvement (RSI) engine, grounded steering triage decider boundaries, an isolated supervisory steering rig topology, and out-of-rig orchestration CLI verbs. This release eliminates decision entropy collapse in heuristic decider ports, establishes automated feedback telemetry from agent executions into policy refinements, and mechanically isolates supervisory governance across multi-rig topologies.

## Grounded steering triage decisions and deterministic decider boundaries

Heuristic decider models operate with deterministic guardrails and unambiguous ranking criteria:

- Deterministic nudge escalation boundaries evaluate session rework rounds and idle durations directly in code (`round >= 2 || idleSec >= 300` triggers `interrupt`, `idleSec >= 120` triggers `standard`, otherwise `gentle`), preventing decider probability flattening and confidence collapse.
- Grounded queue priority selection exposes all ranking comparator dimensions (`blocked`, `reworkRound`, `failuresCount`, `priority`, `createdAt`, `inputOrder`) with explicit lexicographic precedence in prompt instructions and blocked-task safety violation checks.
- Symmetrical defect observation deduplication provides two-pass deterministic matching where strong identifier matches precede title matches, robust `JSON.stringify` title escaping, integer `0` exit code preservation, and conflicting identifier rejection.

## Autonomous closed-loop recursive self-improvement pipeline

Continuous quality and policy refinement are automated through a closed-loop telemetry and synthesis pipeline:

- Out-of-band commit and backlog delta reader tracks active worktree diffs and backlog transitions without mutating or perturbing executing worker squads.
- Dedicated autonomous exploratory dogfood seat (`eval.tester` in `adapters/openrig/agentflow-eval/`) executes exploratory workloads and edge-case validations on isolated worktrees.
- Structured intake finding schema (`schemas/intake-finding.json`) and push-force emitter standardize bug and drift telemetry emission into the governance loop.
- Session trace telemetry extractor extracts tool calls, turn latencies, error states, and compaction events from agent execution transcripts.
- Prompt drift and boundary violation auditor verifies that agents adhere to path ownership, role boundaries, and seat configurations.
- Closed-loop policy and prompt refinement synthesizer analyzes aggregated telemetry and audit findings to generate machine-verifiable policy patches.

## Supervisory steering plane rig topology and orchestration CLI verbs

Supervisory governance is physically separated from worker execution:

- Dedicated `agentflow-steer` base rig topology isolates supervisory governance (`steer.lead`) from delivery execution rigs (`agentflow-core`, `agentflow-eval`).
- Sibling discovery, cross-rig telemetry, and multi-rig audit trail coordinate activity across rigs without leaking execution context.
- Headless CLI verbs (`agentflow-sdlc steer unfreeze`, `agentflow-sdlc steer merge-check`) manage supervisory goals and epoch unfreezes out-of-rig.
- Mechanical enforcement of steering write guards bars steering seats from authoring code commits or modifying implementation assets.

## Skill adapters and harness synchronization

Harness configurations and skill definitions remain strictly aligned across execution environments:

- Skill catalog validation and synchronization ensure parity across Claude Code, Pi, Agy, and Codex harness templates.
- OpenRig adapter templates synchronize seat profiles, culture files, and multi-rig topology configurations.

## Install and update

Node.js 20 or newer is required.

```bash
npm install -g github:smota/agentflow-sdlc#v1.9.0
agentflow-sdlc adapters update openrig
agentflow-sdlc skills sync --apply
```
