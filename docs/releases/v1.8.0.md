# AgentFlow SDLC v1.8.0 — Autonomous decision governance and anti-loop engine

AgentFlow SDLC 1.8.0 delivers an external supervisory steering plane with cryptographic epoch fencing, immutable test oracle lifecycles, pragmatic defect triage (`accept_and_register`), deterministic decision acceleration ports, and pure-function model escalation ladders. This release eliminates autonomous agent rework loops, deadlocks, and metric gaming across multi-agent rigs while establishing strict Two-Plane Separation between supervisory governance and worker execution squads.

## Deterministic ledger circuit breaker and epoch fencing

Autonomous rework loops are eliminated through deterministic, ledger-derived circuit breaking:

- Rework iterations are counted monotonically from the transition ledger keyed per criterion via pure state functions.
- When rework rounds exceed the maximum threshold (`DEFAULT_MAX_REWORK_ROUNDS = 2`), the ledger circuit breaker immediately trips: marks the ledger frozen, increments an integer fencing token, and emits a sealed reverse-seam packet.
- Halts execution cleanly before context exhaustion or infinite retries, barring subsequent commits on the worktree until formal supervisory unfreezing.

## Approval-gated steerer merge verb guard

External supervisory steering is barred from unreviewed code integration:

- The external steering plane (`orch.steer`) operates strictly out-of-rig to govern goals and resolve unfreezes, but cannot self-approve pull requests or execute merge verbs.
- Direct merge attempts are blocked unless an explicit, verified human approval is recorded on the medium.
- Enforces organizational separation between supervisory orchestration and delivery signoff.

## Reverse-seam unfreeze resolution protocol

Frozen ledgers can only resume through an audited, schema-validated resolution workflow:

- Unfreezing requires a sealed `unfreeze-resolution` record signed by supervisory authority with an incremented fencing token.
- Strict unfreeze taxonomy enforces deliberate triage choices: `re-scope`, `slice-split`, `person-waiver`, or `abandonment`.
- Tamper-evident SHA-256 digest sealing ensures unfreeze packets cannot be forged or replayed across epochs.

## Pragmatic defect triage guard and sensitive surface protections

Delivery squads can bypass non-critical blockers without stalling release momentum:

- Pragmatic defect triage (`accept_and_register`) enables supervisory steering to accept auxiliary observations and telemetry edge cases as `accepted-with-conditions`.
- Requires mandatory, idempotent GitHub follow-up issue creation to ensure technical debt is tracked durably.
- Mechanical protections strictly prohibit waiving initial blocker findings, tripped circuit breakers, or sensitive security surfaces (`auth`, `crypto`, `migration`, `billing`).

## Path ownership write guards and test engineer seat

Role separation is mechanically enforced across workspace paths:

- Product Management seats (`pm.*`) are restricted strictly to `.agentflow/**` and `goals/**`; commits modifying application code or test suites are rejected automatically.
- Dedicated Test Engineer seat (`dev.test-eng`) authors verification suites and pre-implementation test oracles under `tests/oracles/**`.
- Phase 3 test oracle digest pinning ensures test criteria cannot be tampered with or modified by builder seats during implementation.

## Deterministic decision policy and model escalation ladder

Autonomous decisions and model resource scaling follow deterministic, reproducible rules:

- Pure-function decision policy evaluates evidence cards and state vectors deterministically without non-deterministic prompt drift.
- Model escalation ladder dynamically scales builder seats to frontier reasoning models only when genuine implementation failures occur across three distinct test failures, completely independent of self-reported model confidence.

## High-throughput decider provider port and authentication adapter

Decision acceleration operates through an isolated provider port:

- Non-causal decision model integration on port 8002 accelerates heuristic triage tasks (queue ordering, deduplication, and nudge escalation) via authenticated Jev headers.
- Protected by an explicit allowlist and backed by automatic offline fallbacks to pure deterministic logic.
- Decider models are strictly banned from granting gate waivers or approving pull requests.

## Architecture and governance policy synchronization

Unified documentation, schemas, and adapter cultures across the framework:

- Full synchronization across repository policy (`AGENTS.md`, `defaults/AGENTS.md`), architecture principles (`docs/guiding-principles.md`), delivery workflows (`docs/agent-workflow.md`), collaboration models (`docs/role-collaboration.md`), runtime platforms, and execution targets.
- OpenRig adapter specifications and cultures (`CULTURE.md`) updated with two-plane governance, path ownership boundaries, and test engineer seat profiles.
