# AgentFlow SDLC v1.6.0 — Dynamic work tree and coordination events

AgentFlow SDLC 1.6.0 introduces dynamic work tree projection across goals, capabilities, and breakdown notes in the Cockpit, along with coordinator execution event exchange and multi-agent phase transition security safeguards.

## Dynamic work tree in the Cockpit

The Cockpit navigation pane renders the work hierarchy dynamically from work-projection contracts on each request:

- Goals display as root items (`◎`) with child capabilities and breakdown notes.
- Admitted capabilities and unadmitted breakdown notes display with status indicators (`○`), clearly marking not-yet-admitted items.
- Replaced notes are omitted when an admitted capability supersedes them via `Replaces #<note>`.
- Prose mentions of `Part of #<parent>` are strictly ignored; parentage requires dedicated whole-line declarations.
- Records with validation findings are surfaced in an isolated rejected work list with explanatory reasons.

## Coordinator event exchange and execution safety

- Cockpit exchanges real-time execution events with the OpenRig DEV coordinator to maintain synchronized delivery states.
- High-assurance review checks strictly validate against capability goal subjects to preserve independent dual control.
- Phase transitions strictly enforce seat boundaries, rejecting requests that attempt to claim or impersonate another seat.

## Install and update

Node.js 20 or newer is required.

```bash
npm install -g github:smota/agentflow-sdlc#v1.6.0
agentflow-sdlc adapters update openrig
```
