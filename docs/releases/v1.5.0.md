# AgentFlow SDLC v1.5.0 — Work records and adapter refresh

## Product checks

`prettier --check .` is clean. A red Product check now means a later command failed.

## Goal, capability, and spec

A standard spec opens when a person accepts that capability's revision. A stored admission still does not open a spec. Templates for the three kinds are in `agents/templates/`.

## Adapter update

`agentflow-sdlc adapters update` keeps installed files the product does not ship, and names them. `--exact` deletes those extras.

## Install

```bash
npm install -g github:smota/agentflow-sdlc#v1.5.0
agentflow-sdlc adapters update openrig
```
