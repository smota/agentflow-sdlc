# AgentFlow SDLC v1.1.0 — Smart Transition Boundaries & Continuous Operability

AgentFlow SDLC 1.1.0 expands the framework with smart transition boundaries, risk-aware execution taxonomy, dual-control human oversight, tamper-evident span ledgers, sandboxed black-box QA, resilient cross-machine handoffs, and an enhanced visual Cockpit command center.

## What you can do with AgentFlow 1.1

### Execute adaptively with risk-aware taxonomy and topological dependency enforcement

- Tailor governance depth dynamically by classifying work into explicit postures: `light` (fast-path documentation and non-functional changes), `standard` (default feature and bug fix delivery), and `high-assurance` (regulated, mission-critical, or security-sensitive changes).
- Enforce topological dependency blocking via `blocked_by` and `blocking` issue relationships, preventing tasks from entering implementation or review while prerequisites remain unfulfilled.
- Guard against accidental phase progression with automated transition preconditions verified before handoffs occur.

### Protect high-consequence gates with interactive dual-control oversight

- Apply the Four-Eyes Principle to sensitive phase transitions and high-assurance gates, requiring an independent sign-off from an authorized reviewer.
- Enforce author-signoff separation to prevent executors from approving their own implementations.
- Authorize transparent waivers when needed with mandatory structured rationale, recorded in cryptographic audit metadata.
- Act on gate dialogs directly within Cockpit or through terminal CLI prompts.

### Audit delivery velocity and lifecycle health with cryptographic span ledgers

- Record every phase duration, role pass, and transition boundary in a tamper-evident, SHA-256 chained span ledger.
- Export OpenTelemetry (OTel) metrics and traces to existing observability collectors without proprietary vendor lock-in.
- Compute real-time DORA software delivery metrics: lead time for changes, deployment cycle time, review latency, and first-pass validation rate.
- Inspect and export comprehensive audit logs in CSV or JSON formats for compliance verification.

### Eliminate pipeline deadlocks with the bounded evidence gate sweeper

- Automatically resolve external CI checks and long-running validation gates through a deterministic three-tier resolution strategy: real-time webhook ingestion, exponential backoff polling, and an enforceable 30-minute fallback timeout.
- Inject raw failure diagnostics directly into downstream agent remediation prompts when external checks fail, enabling immediate autonomous triage.
- Prevent runaway loops and orphaned validation tasks across asynchronous workflows.

### Guarantee test integrity with sandboxed black-box QA and process supervision

- Enforce separation of duties between implementation and validation using role-based tool policies (`roles/tester/tool-policy.json`) that restrict tester agents from modifying source code.
- Execute test suites under a managed `ProcessSupervisor` that guarantees clean process tree termination across Windows (`taskkill /T /F`) and POSIX (`SIGKILL`), preventing runaway dev servers and orphaned background ports.
- Require cryptographic evidence contracts certifying that acceptance observations directly corroborate claimed test results.

### Resume work seamlessly across machines with resilient handoff protocols

- Hand off active workspace state across physical machines and distinct developer operating systems (Windows, macOS, Linux) with POSIX path normalization.
- Prevent multi-agent race conditions and split-brain execution using monotonic lease fencing and expiration timeouts.
- Automatically clear stale `.git/index.lock` locks left behind by interrupted agent processes.
- Scrub sensitive tokens, environment credentials, and secrets prior to persisting checkpoint envelopes.
- Transfer and resume work using dedicated first-class CLI commands: `agentflow-sdlc handoff` and `agentflow-sdlc resume`.

### Operate visually with interactive dependency graphing and DORA metrics

- Visualize task dependencies and topological blockers in real time with visual blocker badges on Cockpit board cards.
- Trigger interactive dual-control sign-off and waiver modals directly from the visual interface.
- Monitor phase cycle times, DORA delivery metrics, and active span traces in the dedicated Metrics & Spans dashboard view (`?view=metrics`).
- Retain GitHub issues, comments, and pull requests as the authoritative source of truth while enjoying an interactive operational command center.

### Anchor agent and human engineering in explicit guiding principles

- Govern all autonomous and pair-programming development through six foundational pillars documented in `docs/guiding-principles.md` and repository policy in `AGENTS.md`.
- Ensure harness neutrality across AI platforms (`claude-cli`, `agy-cli`, `codex-cli`, API endpoints) and maintain compliance-by-design standards across the entire delivery lifecycle.

## Getting started

AgentFlow 1.1 requires Node.js 20 or newer. Adopters can inspect and update their repositories using the CLI:

```bash
# Verify environment readiness
npx -y github:smota/agentflow-sdlc doctor-env --target /path/to/your-project

# Update an existing installation to 1.1.0
node bin/cli.mjs update-prompt --target /path/to/your-project
```

For new adoptions, follow the step-by-step instructions in [Get started](../get-started.md).

## Compatibility and migration

- Version 1.1 is fully backward-compatible with 1.0 installations while introducing optional posture configurations and enhanced gate metadata.
- Workspaces using earlier versions can safely upgrade their configuration without losing existing role passes or lifecycle state.
- Cockpit features remain entirely optional; all SDLC validation and execution paths continue to function completely headless via CLI.
