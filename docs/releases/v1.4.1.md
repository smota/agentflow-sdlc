# AgentFlow SDLC v1.4.1 — Grok 4.7 Routing, Worktree Concurrency & OpenRig Harness

AgentFlow SDLC 1.4.1 establishes Grok 4.7 as the primary reasoning standard for Architect Lead and Reviewer roles, codifies mandatory Git Worktree isolation for builder concurrency, and ships first-class OpenRig harness adapter support with a fully autonomous 6-seat delivery squad.

## Grok 4.7 Lead Routing & Model Catalog Refresh

The canonical model catalog (`.agentflow/model-catalog.json`) assigns `grok-4.7` as the default preferred model for `architect-lead` and `deep-reasoning` tiers, with active fallbacks to `claude-opus-4-6` and `o3-mini`. The agent workflow routing (`agent-workflow.config.json`) configures `grok` (`grok-cli` / `xai-api`) as owner of the `architect`, `reviewer`, `product-manager`, `analyst`, `implementation-planner`, and `pr-readiness` roles, while assigning `developer` to `claude` (`claude-cli`) and `tester` to `codex` (`codex-cli`).

## Mandatory Git Worktree Concurrency

The orchestration model (`.agentflow/orchestration-model.json`) sets `isolatedWorktreeRequired: true` and restricts `maxWriters: 1` per branch. All builder seats execute exclusively within dedicated worktrees under `.worktrees/<branch-name>`, preventing dirty-state collisions and ensuring parallel read access from review and QA seats.

## OpenRig Harness Integration

The repository introduces the OpenRig harness adapter under [`adapters/openrig/`](../../adapters/openrig/):
* **`agentflow` Rig Bundle**: 6-seat pod-aware squad topology (`orch.arch`, `dev.build-jr`, `dev.build`, `dev.build-sr`, `dev.qa`, `rev.review`) with Council deliberative loops.
* **Configurations & Presets**: 8 declared presets (`balanced-claude-lead`, `inverted-codex-lead`, `grok-heavy`, `claude-heavy`, `codex-heavy`, `all-grok`, `all-claude`, `all-codex`).
* **Pi State Bridge**: Integrated support for Grok 4.7 seats via Pi runtime with authenticated OAuth vault linkage.
* **One-line installer and recovery**: `adapters/openrig/scripts/install-rig.sh` for instant setup and recovery across workstations.

## Install and Update

Node.js 20 or newer is required.

```bash
npm install -g github:smota/agentflow-sdlc#v1.4.1
agentflow-sdlc doctor-env
./adapters/openrig/scripts/install-rig.sh
```
