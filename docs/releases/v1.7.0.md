# AgentFlow SDLC v1.7.0 — Goal completion ledgers, reverse seam governance, and multi-seat rig coordination

AgentFlow SDLC 1.7.0 introduces visible goal child completion tracking with structured markdown ledgers, reverse seam governance with multi-seat OpenRig coordination, provider-neutral execution verbs, unified configuration authority, interactive onboarding steppers, built-in agent MCP tools, and transactional refinement pipelines with rollback journals.

## Goal child completion and parts ledger tracking

Goals now provide visible child work tracking and progress metrics without compromising gate stability:

- Structured markdown parts ledger (`| Part | Kind | Title | Status | Replacement | Delivery PR | Commit | Date |`) renders the full delivery history of admitted capabilities and breakdown notes directly on parent goal issues.
- Progress metrics (`total`, `admitted`, `delivered`, `open`, `readyForClosure`) reflect live completion status.
- Goal human gate agreements strip dynamic parts ledgers so operational updates never invalidate prior human signatures or trigger false review drift.
- CLI commands `agentflow-sdlc goal sync <number>`, `agentflow-sdlc goal status <number>`, and `agentflow-sdlc goal ledger <number>` automate ledger updates, validation, and status reporting.

## Reverse seam governance and multi-seat rig coordination

- Closed-loop steering and reverse seam governance enforce boundary preservation and dual-control signoffs across multi-seat rigs.
- Preserves capability contracts and prevents unmonitored scope expansion across collaborative agent topologies.
- Standardized seat topology and execution contracts across OpenRig, Claude, Codex, Gemini, and Grok harnesses.

## Provider-neutral execution verbs and OpenRig adapter

- Structured execution verbs decouple agent role instructions from underlying execution targets and transport protocols.
- Seamless coordination between CLI, session, and API-based execution targets.

## Unified configuration authority and deterministic projection

- Single source of truth configuration authority guarantees determinism across all projected configuration files.
- Automated drift detection surfaces divergence between canonical settings and local project configurations.

## Guided onboarding stepper and cockpit affordances

- Interactive onboarding flow and visual cockpit state guide project bootstrap, workspace initialization, and harness adapter selection.
- Clear visual indicators of worktree isolation and project health.

## Agent MCP tools and conversational maintainer skill suite

- Native Model Context Protocol server (`agentflow-mcp`) provides tools for autonomous coding agents to inspect SDLC state, review evidence, and transition phases.
- Comprehensive conversational maintainer skill suite empowers agents to assist users with project alignment and delivery assurance.

## Transactional refinement pipeline with rollback journals

- Safe refinement pipeline protects project state across complex multi-step delivery phases.
- Rollback journal logging ensures graceful recovery if unexpected failures occur during stage transitions.

## Install and update

Node.js 20 or newer is required.

```bash
npm install -g github:smota/agentflow-sdlc#v1.7.0
agentflow-sdlc adapters update openrig
agentflow-sdlc skills sync --apply
```
