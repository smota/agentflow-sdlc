# AgentFlow SDLC v1.11.0 — OpenRig 0.7.6 without a package dependency

AgentFlow SDLC 1.11.0 keeps OpenRig optional. The adapter now targets OpenRig CLI and daemon 0.7.6, and an adopting repository can join an installed spec without copying a rig topology and without adding an OpenRig npm package.

## One spec, many repositories

Install the delivery, product, and steer bases once. A second checkout joins that same spec.

```bash
agentflow-sdlc adapters install openrig
agentflow-sdlc adapters catalog openrig --preview --cwd /path/to/repo
agentflow-sdlc adapters catalog openrig --write --cwd /path/to/repo
rig up agentflow --name <rig> --cwd /path/to/repo
```

`adapters catalog` previews by default. `--write` adds `project.yaml` and one workspace entry. It does not call `rig`, copy a rig, or install OpenRig. OpenRig itself is installed separately by the operator. Delivery, product, and steer stay separate specs.

## Human channel, seat authority, and connectors

- Human decisions go to a registered `<entityId>@external` address through `rig gateway`. `rig send` reaches an agent terminal only. The run CLI still refuses a self-supplied attestation.
- Claude tool rules live in the rig spec as `claude_permissions`, or on an existing seat through `rig seat set-permissions`. OpenRig does not write those rules into project Claude settings. Account homes, when used, are absolute `CLAUDE_CONFIG_DIR` or `CODEX_HOME` values under member or rig `env:`.
- `rig mcp serve` stays optional and off. A listed MCP tool is not a grant. Hosted members stay unsupported.

## Install and update

Node.js 20 or newer is required. OpenRig 0.7.6 or newer is required only when you use the OpenRig adapter.

```bash
npm install -g github:smota/agentflow-sdlc#v1.11.0
agentflow-sdlc adapters update openrig
```

`adapters update` refreshes the AgentFlow bases. It does not install or upgrade OpenRig.

## Compatibility

This is a minor release. S0 and S1 projects that do not use OpenRig keep the same path. The adapter floor moves from OpenRig 0.6.6 to 0.7.6 for S2. No `@openrig` package is added.
