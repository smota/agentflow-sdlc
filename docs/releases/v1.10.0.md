# AgentFlow SDLC v1.10.0 — Adaptive execution substrates, Lean 4-Seat default, and effort-degradation guard

AgentFlow SDLC 1.10.0 introduces adaptive substrate detection (`S0` Single-CLI + L2 Subagents, `S1` Multi-CLI Orthogonal Routing, `S2` OpenRig Lean 4-Seat Squad), the 2026 frontier model catalog with effort-degradation guards, composite Phase 3–5 builder passes for bounded and standard slices, and multi-agent throughput and continuity safeguards across OpenRig execution squads.

## Adaptive execution substrates (`S0` / `S1` / `S2`) and onboarding

Repositories automatically calibrate their collaboration topology to the developer's installed CLI environment without requiring OpenRig by default:

- `detectExecutionSubstrate()` in `lib/environment.mjs` inspects installed agent CLIs (`claude`, `codex`, `agy`, `grok`, `pi`) and OpenRig (`rig`) to recommend `s0-single-cli`, `s1-multi-cli`, or `s2-openrig-squad`.
- The onboarding wizard (`lib/onboarding/wizard.mjs`) surfaces the detected substrate tier, recommended squad preset (`lean-4-seat`), composite builder ceiling (`P1`), and effort policy (`defaultLoopEffort: medium`, `subagentSearchEffort: low`).
- Two-level hierarchy separates **L1 Persistent Governance Seats** (which own phase transitions, oracle pins, and independent sign-off) from **L2 Ephemeral Subagents** (spawned inside a seat's worktree for bounded parallel exploration, test writing, or mechanical edits).

## 2026 frontier model catalog and Effort-Degradation Guard

Frontier models degrade in long-context iterative coding loops when pinned at `effort: high`. AgentFlow 1.10.0 enforces task- and context-aware effort calibration:

- Updated `.agentflow/model-catalog.json` and `lib/config/projection.mjs` with 2026 frontier models (`gemini-4-argon`, `gemini-3.8-flash`, `gpt-6-astra`, `gpt-6.1-sol`, `grok-4.7`, `d3-flash`) and explicit `effortCeiling` metadata.
- `resolveEffortCalibration()` in `lib/role-routing.mjs` and `enforceEffortDegradationGuard()` in `adapters/openrig/platform-fallback.mjs` clamp persistent execution loops to `effort: medium` (`effort: low` for `dev.qa`, `eval.tester`, and `P0` slices), reserving `effort: high` strictly for clean-context (<40k token) one-shot architecture synthesis (`P3`/`P4`) or adversarial Phase 6 review bursts.
- `runConfigDoctor()` in `lib/config/doctor.mjs` warns when `effortPolicy.defaultLoopEffort` is set to `'high'` or when `optional-multi-agent` routing assigns the same owner to developer and reviewer without self-review disclosure.

## OpenRig Lean 4-Seat default and Composite Phase 3–5 Builder Pass

OpenRig delivery squads default to a leaner, higher-throughput topology while preserving Classic 6-Seat opt-in:

- Default `adapters/openrig/agentflow/rig.yaml` provisions the **Lean 4-Seat Squad** (`orch.arch`, `dev.build`, `dev.qa`, `rev.review` + `eval.tester` daemon) calibrated at `effort: medium` and `effort: low`.
- Added `frontline` and `all-antigravity` presets and `effort_policy` to `adapters/openrig/agentflow/configurations.yaml` and `adapters/openrig/agentflow-product/configurations.yaml`.
- For `P0` and `P1` slices that do not touch `tests/oracles/**`, `resolveCompositePhaseWindow()` and `resolvePhaseCompression()` allow the builder to execute a **Composite Phase 3–5 Builder Pass** in a single worktree turn before handing off to an orthogonal family for Phase 6 review.

## Multi-agent throughput, fallback, and continuity safeguards

- Three-tier builder routing (`tier-routing.mjs`), sticky builder return affinity across `4 -> 3 -> 4` rework loops, and unmerged-accepted pipeline admission caps (`canAdmitNextSlice`).
- Outbox handoff step (`handoff-step.mjs`), pointer envelopes, and multi-writer admission in `agentflow-product`.
- Two-level model fallback (`platform-fallback.mjs`) and dynamic four-eyes reviewer dispatch (`resolveFourEyesReviewerTarget`) with mid-phase switch protection.
- Phase-boundary context headroom gates (`continuity-policy.mjs`), supervisor liveness breaker, and non-disruptive `btw` steering mode (`scripts/steer.mjs`).

## Install and update

Node.js 20 or newer is required.

```bash
npm install -g github:smota/agentflow-sdlc#v1.10.0
agentflow-sdlc adapters update openrig
agentflow-sdlc skills sync --apply
```
